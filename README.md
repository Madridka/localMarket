# Рядом

Интерактивный прототип локальной площадки объявлений для Томска и области. Написан на HTML, CSS и JavaScript без библиотек и сервера приложений.

## Запуск

Откройте [index.html](index.html) двойным щелчком. Это единственная стартовая страница; каталог, карточки, создание объявления и остальные разделы открываются по ссылкам из неё. Сервер и установка зависимостей не нужны.

Если меняете исходные файлы в `js/`, пересоберите локальный скрипт командой `node tools/build-static.mjs`. Готовый `js/app.bundle.js` уже включён в проект, поэтому для обычного запуска команда не требуется.

## Данные

В `js/data.js` находятся 80 тестовых объявлений, 10 продавцов, отзывы и переписки. Дерево категорий и характеристики товаров описаны в `js/categories.js`. Фотографии включены в `assets/images`, поэтому каталог работает без внешних запросов. Избранное, переписки, опубликованные объявления и поиски сохраняются в `localStorage` браузера.

Координаты тестовых объявлений демонстрационные. Расстояние считается от центра выбранного города либо, после явного разрешения, от местоположения пользователя. Объявления, для которых указан только город, показываются без числа километров.

Фотографии взяты с [Unsplash](https://unsplash.com/) для демонстрации прототипа. Объявления и продавцы вымышлены.
