# Рядом

Интерактивный прототип локальной площадки объявлений для Томска и области. Написан на HTML, CSS и JavaScript без библиотек и сервера приложений.

## Запуск

Откройте [index.html](index.html) прямо из папки. Каталог, карточки, создание объявления и остальные разделы работают через готовый автономный скрипт без сервера и сторонних зависимостей.

## Данные

В `js/data.js` находятся 80 тестовых объявлений, 10 продавцов, отзывы и переписки. Дерево категорий и характеристики товаров описаны в `js/categories.js`. Фотографии включены в `assets/images`, поэтому каталог работает без внешних запросов. Избранное, переписки, опубликованные объявления и поиски сохраняются в `localStorage` браузера.

Координаты тестовых объявлений демонстрационные. Фильтр считает расстояние от центра выбранного города и показывает объявления в выбранном радиусе. Геолокация пользователя не запрашивается.

Фотографии взяты с [Unsplash](https://unsplash.com/) для демонстрации прототипа. Объявления и продавцы вымышлены.
