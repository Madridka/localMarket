# Рядом

Frontend SPA локальной площадки объявлений. Проект мигрирован на Vue 3, TypeScript, Vue Router, Pinia, Tailwind CSS и vue-i18n. Сейчас он работает с тестовыми данными и совместимым `localStorage`; Express API подключается через repository-адаптеры.

## Требования

- Bun 1.2.21 или совместимая более новая версия.
- Современный Chrome/Edge, Firefox или Safari с поддержкой Tailwind CSS v4.

## Будущий Express-сервер

Frontend обращается к асинхронным repository-интерфейсам. Для подключения API нужно реализовать HTTP-адаптеры и переключить composition root, не меняя компоненты и Pinia stores. Подробности находятся в `docs/architecture.md`.

Production-сервер должен обслуживать `/api` и статику `dist`, а затем возвращать `dist/index.html` для остальных GET-запросов, чтобы работал Vue Router history mode.
