# Рядом

Интерактивный прототип локальной площадки объявлений для Томска и области. Написан на HTML, CSS и JavaScript без библиотек и сервера приложений.

## Запуск

В папке проекта выполните:

```powershell
python -m http.server 4173
```

Откройте `http://127.0.0.1:4173/index.html`. Локальный сервер нужен для загрузки JavaScript-модулей в браузерах с ограничениями для `file://`.

## Данные

В `js/data.js` находятся 36 тестовых объявлений, 10 продавцов, отзывы и переписки. Фотографии включены в `assets/images`, поэтому каталог работает без внешних запросов. Избранное, переписки, опубликованные объявления и поиски сохраняются в `localStorage` браузера.

Фотографии взяты с [Unsplash](https://unsplash.com/) для демонстрации прототипа. Объявления и продавцы вымышлены.
